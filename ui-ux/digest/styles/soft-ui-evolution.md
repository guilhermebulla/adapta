# Soft UI Evolution

- id: `soft-ui-evolution`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Medium
- era: 2020s Modern  ·  frameworks: tailwind/mui/chakra
- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Modern enterprise apps, SaaS platforms, health/wellness, modern business tools, professional, hybrid

## Não usar para
Extreme minimalism, critical performance, systems without modern OS

## Cores primárias
Improved contrast pastels: Soft Blue #87CEEB, Soft Pink #FFB6C1, Soft Green #90EE90, better hierarchy

## Cores secundárias
Better combinations, accessible secondary, supporting with improved contrast, modern accents

## Efeitos & animação
Improved shadows (softer than flat, clearer than neumorphism), modern (200-300ms), focus visible, measured contrast targets

## Tokens
```css
--shadow-soft: modern blend, --border-radius: 10px, --animation-duration: 200-300ms, --contrast-ratio: 4.5:1+, --color-hierarchy: improved, --wcag-target: project-defined
```

## Checklist
Contrast measured against the chosen project target, 
- Soft shadows modern, 
- Border-radius 8-12px, 
- Animations 200-300ms, 
- Focus states visible, 
- Color hierarchy clear

## Prompt de referência
Design evolved neumorphism with improved contrast (measured contrast targets), modern aesthetics, subtle depth, accessibility focus. Use soft shadows (softer than flat but clearer than pure neumorphism), better color hierarchy, improved focus states, modern 200-300ms animations.

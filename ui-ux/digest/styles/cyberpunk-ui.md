# Cyberpunk UI

- id: `cyberpunk-ui`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Medium
- era: 2020s Cyberpunk  ·  frameworks: tailwind/css
- light/dark: not-recommended / supported  ·  perf: cost:moderate/drivers:animation,blur  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Gaming platforms, tech products, crypto apps, sci-fi applications, developer tools, entertainment

## Não usar para
Corporate enterprise, healthcare, family apps, conservative brands, elderly users

## Cores primárias
#00FF00 (Matrix Green), #FF00FF (Magenta), #00FFFF (Cyan), #0D0D0D (Dark)

## Cores secundárias
Neon gradients, scanline overlays, glitch colors, terminal green accents

## Efeitos & animação
Neon glow (text-shadow), glitch animations (skew/offset), scanlines (::before overlay), terminal fonts

## Tokens
```css
--bg-dark: #0D0D0D, --neon-green: #00FF00, --neon-magenta: #FF00FF, --neon-cyan: #00FFFF, --scanline-opacity: 0.1, --glitch-duration: 0.3s
```

## Checklist
Dark background only, 
- Neon accents visible, 
- Glitch effect subtle, 
- Scanlines optional, 
- Monospace font, 
- Terminal aesthetic

## Prompt de referência
Design a cyberpunk interface. Use: neon colors on dark (#0D0D0D), terminal/HUD aesthetic, glitch effects, scanlines overlay, matrix green accents, monospace fonts, angular shapes, dystopian tech feel.

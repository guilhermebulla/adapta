# Glassmorphism

- id: `glassmorphism`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Medium
- era: 2020s Modern  ·  frameworks: tailwind/mui/chakra
- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:conditional/requires:contrast-text-4.5,keyboard,visible-focus,reduced-moti…

## Best for
Modern SaaS, financial dashboards, high-end corporate, lifestyle apps, modal overlays, navigation

## Não usar para
Low-contrast backgrounds, critical accessibility, performance-limited, dark text on dark

## Cores primárias
Translucent white: rgba(255,255,255,0.1-0.3)

## Cores secundárias
Vibrant: Electric Blue #0080FF, Neon Purple #8B00FF, Vivid Pink #FF1493, Teal #20B2AA

## Efeitos & animação
Backdrop blur (10-20px), subtle border (1px solid rgba white 0.2), light reflection, Z-depth

## Tokens
```css
--blur-amount: 15px, --glass-opacity: 0.15, --border-color: rgba(255,255,255,0.2), --background: vibrant color, --text-color: light/dark based on BG
```

## Checklist
Backdrop-filter blur 10-20px, 
- Translucent white 15-30% opacity, 
- Subtle border 1px light, 
- Vibrant background verified, 
- Text contrast 4.5:1 checked

## Prompt de referência
Design a glassmorphic interface with frosted glass effect. Use backdrop blur (10-20px), translucent overlays (rgba 10-30% opacity), vibrant background colors, subtle borders, light source reflection, layered depth. Perfect for modern overlays and cards.

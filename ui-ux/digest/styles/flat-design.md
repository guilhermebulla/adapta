# Flat Design

- id: `flat-design`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Low

- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Web apps, mobile apps, cross-platform, startup MVPs, user-friendly, SaaS, dashboards, corporate

## Não usar para
Complex 3D, premium/luxury, artistic portfolios, immersive experiences, high-detail

## Cores primárias
Solid bright: Red, Orange, Blue, Green, limited palette (4-6 max)

## Cores secundárias
Complementary colors, muted secondaries, high saturation, clean accents

## Efeitos & animação
No gradients/shadows, simple hover (color/opacity shift), fast loading, clean transitions (150-200ms ease), minimal icons

## Tokens
```css
--shadow: none, --color-palette: 4-6 solid, --border-radius: 2px, --gradient: none, --icons: simplified SVG, --animation: minimal 150-200ms
```

## Checklist
No shadows/gradients, 
- 4-6 solid colors max, 
- Clean lines consistent, 
- Simple shapes used, 
- Icon-heavy layout, 
- High saturation colors, 
- Fast loading verified

## Prompt de referência
Create a flat, 2D interface with bold colors, no shadows/gradients, clean lines, simple geometric shapes, icon-heavy, typography-focused, minimal ornamentation. Use 4-6 solid, bright colors in a limited palette with high saturation.

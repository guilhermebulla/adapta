# Financial Dashboard

- id: `financial-dashboard`  ·  tipo: BI/Analytics  ·  status: supplemental
- pai: `data-dense-dashboard`  ·  complexidade: Medium
- era: 2020s Modern  ·  frameworks: recharts/chartjs/d3
- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Financial reporting, accounting dashboards, portfolio tracking, budget monitoring, banking analytics

## Não usar para
Simple business dashboards, entertainment/social metrics, non-financial data

## Cores primárias
Financial colors: profit (green #22C55E), loss (red #EF4444), neutral (grey), trust (dark blue #003366)

## Cores secundárias
Revenue highlight (green), expenses (red), budget variance (orange/red), balance (grey), accuracy (blue)

## Efeitos & animação
Number animations (count-up), trend direction indicators, percentage change animations, profit/loss color transitions

## Tokens
```css
--currency-symbol: $, --decimal-places: 2, --profit-color: #22C55E, --loss-color: #EF4444, --variance-threshold: 10%, --table-header-bg: #F3F4F6
```

## Checklist
Currency formatted, 
- Decimals consistent, 
- P&L clear, 
- Budget variance shown, 
- Audit trail complete, 
- Export to Excel

## Prompt de referência
Design a financial dashboard. Use: revenue/expense charts, profit margins, budget vs actual, cash flow waterfall, financial ratios, audit trail table, currency formatting, period comparisons.

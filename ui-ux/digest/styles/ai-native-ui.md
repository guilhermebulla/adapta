- id: `ai-native-ui`  ·  tipo: General  ·  status: active

- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
AI products, chatbots, voice assistants, copilots, AI-powered tools, conversational interfaces

## Não usar para
Traditional forms, data-heavy dashboards, print-first content

## Cores primárias
Neutral + single accent, #6366F1 (AI Purple), #10B981 (Success), #F5F5F5 (Background)

## Cores secundárias
Status indicators, streaming highlights, context card colors, subtle accent variations

## Efeitos & animação
Typing indicators (3-dot pulse), streaming text animations, pulse animations, context cards, smooth reveals

## Tokens
```css
--ai-accent: #6366F1, --user-bubble-bg: #E0E7FF, --ai-bubble-bg: #F9FAFB, --input-height: 48px, --typing-dot-size: 8px, --message-gap: 16px
```

## Checklist
Chat layout responsive, 
- Typing indicator smooth, 
- Input always visible, 
- Context cards styled, 
- AI responses distinct, 
- User messages aligned right

## Prompt de referência
Design an AI-native interface. Use: minimal chrome, conversational layout, streaming text area, typing indicators (3-dot pulse), context cards, subtle AI accent color (#6366F1), clean input field, response bubbles.

# Parallax Storytelling

- id: `parallax-storytelling`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: High
- era: 2020s Modern  ·  frameworks: custom/locomotive-scroll

## Best for
Brand storytelling, product launches, case studies, portfolios, annual reports, marketing campaigns

## Não usar para
E-commerce, dashboards, mobile-first, SEO-critical, accessibility-required

## Cores primárias
Story-dependent, often gradients and natural colors, section-specific palettes

## Cores secundárias
Section transition colors, depth layer colors, narrative mood colors

## Efeitos & animação
transform: translateY(scroll), position: fixed/sticky, perspective: 1px, scroll-triggered animations

## Tokens
```css
--parallax-speed-bg: 0.3, --parallax-speed-mid: 0.6, --parallax-speed-fg: 1, --section-height: 100vh, --transition-duration: 600ms, --perspective: 1px
```

## Checklist
Layers parallax smoothly, 
- Story flows naturally, 
- Mobile alternative provided, 
- Performance optimized, 
- Skip option available, 
- Reduced motion fallback

## Prompt de referência
Design a parallax storytelling page. Use: scroll-driven narrative, layered backgrounds (3-5 layers), fixed/sticky sections, cinematic transitions, progressive disclosure, full-screen chapters, depth perception.

# Hero-Centric Design

- id: `hero-centric-design`  ·  tipo: Landing Page  ·  status: deprecated

- era: 2020s Modern  ·  frameworks: tailwind/bootstrap

## Best for
SaaS landing pages, product launches, service landing pages, B2B platforms, tech companies

## Não usar para
Complex navigation, multi-page experiences, data-heavy applications

## Cores primárias
Brand primary color, white/light backgrounds for contrast, accent color for CTA

## Cores secundárias
Supporting colors for secondary CTAs, accent highlights, trust elements (testimonials, logos)

## Efeitos & animação
Smooth scroll reveal, fade-in animations on hero, subtle background parallax, CTA glow/pulse effect

## Tokens
```css
--hero-min-height: 100vh, --headline-size: clamp(2rem, 5vw, 4rem), --cta-padding: 1rem 2rem, --overlay-opacity: 0.5, --text-shadow: 0 2px 4px rgba(0,0,0,0.3)
```

## Checklist
Hero section full viewport height, 
- Headline visible above fold, 
- CTA button high contrast, 
- Background image optimized (WebP), 
- Text readable on background, 
- Mobile responsive layout

## Prompt de referência
Design a hero-centric landing page. Use: full-width hero section, compelling headline (60-80 chars), high-contrast CTA button, product screenshot or video, value proposition above fold, gradient or image background, clear visual hierarchy.

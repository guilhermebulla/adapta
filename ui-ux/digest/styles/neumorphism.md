# Neumorphism

- id: `neumorphism`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Medium
- era: 2020s Modern  ·  frameworks: tailwind/css-in-js
- light/dark: supported / conditional  ·  perf: cost:low/drivers:none  ·  a11y: risk:high/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Health/wellness apps, meditation platforms, fitness trackers, minimal interaction UIs

## Não usar para
Complex apps, critical accessibility, data-heavy dashboards, high-contrast required

## Cores primárias
Light pastels: Soft Blue #C8E0F4, Soft Pink #F5E0E8, Soft Grey #E8E8E8

## Cores secundárias
Tints/shades (±30%), gradient subtlety, color harmony

## Efeitos & animação
Soft box-shadow (multiple: -5px -5px 15px, 5px 5px 15px), smooth press (150ms), inner subtle shadow

## Tokens
```css
--border-radius: 14px, --shadow-soft-1: -5px -5px 15px, --shadow-soft-2: 5px 5px 15px, --color-light: #F5F5F5, --color-primary: single pastel
```

## Checklist
Rounded corners 12-16px consistent, 
- Multiple shadow layers (2-3), 
- Pastel color verified, 
- Monochromatic palette checked, 
- Press animation smooth 150ms

## Prompt de referência
Create a neumorphic UI with soft 3D effects. Use light pastels, rounded corners (12-16px), subtle soft shadows (multiple layers), no hard lines, monochromatic color scheme with light/dark variations. Embossed/debossed effect on interactive elements.

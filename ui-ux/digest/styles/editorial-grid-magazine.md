## Best for
News sites, blogs, magazines, editorial content, long-form articles, journalism, publishing

## Não usar para
Dashboards, apps, e-commerce catalogs, real-time data, short-form content

## Cores primárias
High contrast: Black #000000, White #FFFFFF, accent brand color

## Cores secundárias
Muted supporting, pull quote highlights, byline colors, section dividers

## Efeitos & animação
Smooth scroll, reveal on scroll, parallax images, text animations, page-flip transitions

## Tokens
```css
--grid-cols: asymmetric, --body-font: Georgia/Merriweather, --heading-font: bold sans, --drop-cap-size: 4em, --pull-quote-size: 1.5em, --column-gap: 2rem
```

## Checklist
Grid asymmetric, 
- Typography editorial, 
- Pull quotes styled, 
- Drop caps present, 
- Images large/impactful, 
- Mobile reflows well

## Prompt de referência
Design an editorial magazine layout. Use: asymmetric grid, pull quotes, drop caps, multi-column text, large imagery, bylines, section dividers, print-inspired typography, article hierarchy, white space balance.

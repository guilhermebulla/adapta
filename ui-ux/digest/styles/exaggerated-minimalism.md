# Exaggerated Minimalism

- id: `exaggerated-minimalism`  ·  tipo: General  ·  status: active
- pai: ``  ·  complexidade: Low
- era: 2020s Modern  ·  frameworks: tailwind/custom
- light/dark: supported / supported  ·  perf: cost:low/drivers:none  ·  a11y: risk:low/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Fashion, architecture, portfolios, agency landing pages, luxury brands, editorial

## Não usar para
E-commerce catalogs, dashboards, forms, data-heavy, elderly users, complex apps

## Cores primárias
#000000 (Black), #FFFFFF (White), single vibrant accent only

## Cores secundárias
Minimal - single accent color, no secondary colors, extreme restraint

## Efeitos & animação
font-size: clamp(3rem 10vw 12rem), font-weight: 900, letter-spacing: -0.05em, massive whitespace

## Tokens
```css
--type-giant: clamp(3rem, 10vw, 12rem), --type-weight: 900, --spacing-huge: 8rem, --color-primary: #000000, --color-bg: #FFFFFF, --accent: single color only
```

## Checklist
Typography oversized, 
- White space extreme, 
- Black/white dominant, 
- Single accent only, 
- Elements minimal, 
- Statement clear

## Prompt de referência
Design with exaggerated minimalism. Use: oversized typography (clamp 3rem-12rem), extreme negative space, black/white primary, single accent color only, bold statements, minimal elements, dramatic contrast.

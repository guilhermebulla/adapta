- pai: `retro-futurism`  ·  complexidade: Medium
- era: 1980s-90s Retro  ·  frameworks: tailwind/css-in-js
- light/dark: supported / supported  ·  perf: cost:moderate/drivers:animation,blur  ·  a11y: risk:high/requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion

## Best for
Music platforms, gaming, creative portfolios, tech startups, entertainment, artistic projects

## Não usar para
Business apps, e-commerce, education, healthcare, enterprise software

## Cores primárias
#FF71CE (Pink), #01CDFE (Cyan), #05FFA1 (Mint), #B967FF (Purple)

## Cores secundárias
Sunset gradients, glitch overlays, VHS effects, neon accents, pastel variations

## Efeitos & animação
text-shadow glow, linear-gradient, filter: hue-rotate(), glitch animations, retro scan lines

## Tokens
```css
--vapor-pink: #FF71CE, --vapor-cyan: #01CDFE, --vapor-mint: #05FFA1, --vapor-purple: #B967FF, --grid-color: rgba(255,255,255,0.1), --glow-intensity: 15px
```

## Checklist
Sunset gradient present, 
- Neon glow applied, 
- Retro grid visible, 
- Glitch effects subtle, 
- Dreamy atmosphere, 
- 80s-90s aesthetic

## Prompt de referência
Design a vaporwave aesthetic interface. Use: sunset gradients (pink/cyan/purple), 80s-90s nostalgia, glitch effects, Greek statue imagery, palm trees, grid patterns, neon glow, retro-futuristic feel, dreamy atmosphere.

## Best for
Simple service landing pages, indie products, consulting services, micro SaaS, freelancer portfolios

## Não usar para
Feature-heavy products, complex explanations, multi-product showcases

## Cores primárias
Monochromatic primary, white background, single accent color for CTA, black/dark grey text

## Cores secundárias
Minimal secondary colors, reserved for critical CTAs only, neutral supporting elements

## Efeitos & animação
Very subtle hover effects, minimal animations, fast page load (no heavy animations), smooth scroll

## Tokens
```css
--content-max-width: 680px, --spacing-large: 4rem, --font-size-body: 18px, --line-height: 1.6, --color-text: #1a1a1a, --color-bg: #ffffff
```

## Checklist
Single column centered, 
- White space generous, 
- One primary CTA only, 
- No decorative images, 
- Page weight < 500KB, 
- Load time < 2s

## Prompt de referência
Design a minimal direct landing page. Use: single column layout, maximum white space, essential content only, one CTA, clean typography, no decorative elements, fast loading, direct messaging.
